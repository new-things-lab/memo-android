# MEMO Whiteboard Scanner for Android

Direct APK downloads of the MEMO app by [New Things Lab](https://newthingslab.com), for Android phones without Google Play (for example de-Googled or e-ink phones).

Most people should install MEMO from [Google Play](https://play.google.com/store/apps/details?id=com.NewThingsLab.MEMOApp) or the [App Store](https://apps.apple.com/app/memo-whiteboard-scanner/id6758513056) instead: those update automatically.

## Download

**[Download the latest APK](https://github.com/new-things-lab/memo-android/releases/latest/download/MEMO-android.apk)**

Each APK here is the exact build Google Play delivers, signed by Google Play. You can switch to the Play Store version later without reinstalling.

## Install

1. Download the APK on your phone, or on a computer and copy it over.
2. Open it and allow installing apps from this source when Android asks.

On a Mudita Kompakt, install it through Mudita Center over USB.

## Good to know

- Sideloaded apps do not update themselves. Come back here for new versions; each release lists its SHA-256 checksum.
- In-app purchases need Google Play. Without it, unlock MEMO AI Pro with an activation code: Settings › Account & access › Activate a code.
- This repository only hosts app downloads; it does not contain source code.
